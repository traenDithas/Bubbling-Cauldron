# 🧪 Bubbling Cauldron (Mobile Game)

A 2D arcade puzzle game with a Halloween setting, developed using **Unity** and **C#**.
The goal is to brew the correct potions under time pressure, following dynamically changing recipes.

![Gameplay Screenshot](https://github.com/traenDithas/Bubbling-Cauldron/blob/main/Assets/Reference/Images/iPhone_Reference.jpg)

## 🚀 About the Project
This project serves as a **portfolio showcase** for my software development skills in C# and Unity.
It demonstrates the implementation of game logic, UI management, and data structures.

**Key Feature:** The project was built using an "AI-Assisted Development" approach. As the Lead Developer, I designed the architecture and logic, utilizing AI tools (Google Gemini) as a "Co-Pilot" for efficient coding.

## 🛠️ Tech Stack
* **Engine:** Unity 2022 (2D & 3D elements)
* **Language:** C#
* **IDE:** VS Code
* **Version Control:** Git & GitHub
* **Architecture:** Component-based design

## 💻 Code Highlights
The core of the game is the `RecipeManager`, which controls the main gameplay loop.
Key implemented concepts include:
* **List Manipulation:** Dynamic adding and removing of ingredients (`List<IngredientData>`).
* **Reverse Iteration:** Safely removing objects from active lists during runtime.
* **Event Handling:** Communication between `ScoreManager`, `Spawner`, and `UI`.

## 🎮 Features
* Dynamic Recipe System (Random Generation)
* Increasing Difficulty (Level System)
* Highscore Tracking
* Animated UI Feedback

## 📂 Installation / How to Play
1.  Clone the repository: `git clone https://github.com/traenDithas/Bubbling-Cauldron.git`
2.  Open in Unity Hub (Version 2022.x recommended).
3.  Open `MainScene` in the `Scenes` folder and press Play.
